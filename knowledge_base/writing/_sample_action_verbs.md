# Verbos de ação para currículos de tecnologia

Cada bullet de currículo deve começar com um verbo de ação no passado. Verbo
genérico ("trabalhei", "ajudei", "participei") enfraquece — soa como espectador.
Verbo específico ("construí", "liderei", "diagnostiquei") posiciona o candidato
como protagonista.

## Verbos de construção e implementação

Use quando descrever criação de algo do zero ou entrega concreta de feature.

- **construí** — apropriado pra sistemas, APIs, pipelines.
- **implementei** — apropriado pra features, algoritmos, integrações.
- **desenvolvi** — genérico mas aceitável quando o objeto é específico.
- **arquitetei** — usa quando você desenhou a estrutura, não só codou.
- **migrei** — quando moveu sistema/dado de uma tecnologia pra outra.

Exemplo bom: "Construí pipeline ETL em Airflow processando 2M de registros/dia
de PostgreSQL pra Snowflake."

Exemplo ruim: "Trabalhei com Airflow processando dados."

## Verbos de análise e investigação

Use quando descrever trabalho diagnóstico, exploratório, ou de pesquisa.

- **analisei** — dados, código, performance, métricas.
- **investiguei** — bugs, incidentes, regressões.
- **diagnostiquei** — root cause de problema técnico.
- **mensurei** — quando produziu números antes inexistentes.
- **identifiquei** — gap, oportunidade, vulnerabilidade.

Exemplo bom: "Diagnostiquei contention de locks em queries de relatório
reduzindo p99 de 8s pra 800ms via reindex + materialized view."

## Verbos de liderança e coordenação

Use quando descrever responsabilidade sobre pessoas ou processos.

- **liderei** — projeto, equipe, iniciativa.
- **coordenei** — entre squads, com stakeholders.
- **orquestrei** — múltiplas frentes técnicas convergindo.
- **mentorei** — pessoas mais juniores.
- **facilitei** — workshops, decisões de arquitetura.

Cuidado: liderança técnica diferente de liderança formal. Se você "liderou" sem
título de tech lead, deixe o contexto claro ("Liderei a frente técnica de
autenticação em projeto de 4 devs").
