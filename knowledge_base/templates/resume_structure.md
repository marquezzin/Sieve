# Estrutura padrão recomendada

Regras de montagem do currículo: tamanho, seções obrigatórias, ordem e formatação. O
currículo deve ser **adaptado para cada vaga** — não existe currículo genérico ideal.

## Tamanho por anos de experiência

| Experiência | Páginas recomendadas |
|---|---|
| 0–5 anos | 1 página (máximo) |
| 5–10 anos | Até 2 páginas |
| 10+ anos | Até 3 páginas — mas menos é mais |

## Seções obrigatórias

Todo currículo de tecnologia deve ter: **Experiência, Educação e Habilidades**. Cada
elemento claramente delimitado — grau e instituição na educação; empresa, cargo e datas na
experiência; habilidades organizadas por categoria.

## Ordem das seções

Muda conforme o momento de carreira.

**Sem experiência profissional:**
1. Contatos (header)
2. Educação
3. Projetos
4. Certificações relevantes
5. Honors / prêmios
6. Idiomas

**Com experiência profissional:**
1. Contatos (header)
2. Experiência profissional
3. Educação
4. Certificações relevantes
5. Projetos
6. Honors / prêmios
7. Idiomas

## Sobre certificações

Incluir apenas certificações com peso real no mercado — Databricks, GCP, AWS, CKA.
Certificados de plataformas como Udemy não têm valor significativo e ocupam espaço.

## Seção de habilidades técnicas

- Linguagens e ferramentas devem estar proeminentemente visíveis.
- Atenção a dependências implícitas: Django pressupõe Python; Node.js pressupõe JavaScript
  (e frequentemente TypeScript). Não liste uma sem a outra.
- Cada experiência pode ter uma seção própria de "tech stack" listando as tecnologias
  daquele emprego (opcional, recomendado).

## Formatação geral

- Bullet points consistentes nas experiências.
- Negrito e itálico só para o que é realmente importante.
- Datas sempre no mesmo formato (`01/2025` **ou** `January 2025`, nunca misturar).
- Nome de arquivo profissional com o nome do candidato (`joao_silva_cv.pdf`).
- Sem erros gramaticais ou de digitação — peer review é altamente recomendado.

## O que remover

- Experiências irrelevantes para o cargo atual (ex: 10 anos em Java não precisa listar
  atendente de supermercado de 11 anos atrás).
- Soft skills exageradas e genéricas.
- Certificações de cursinhos sem peso no mercado.
